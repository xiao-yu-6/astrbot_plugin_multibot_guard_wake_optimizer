# v0.7.7 代码审查修订

基于 v0.7.6 的代码审查修订；以 v0.7.7 源码提交维护。项目不创建 GitHub Release 或打包安装文件。

1. **原生空唤醒绕过巡检**：独立语义模式下，避免框架更高优先级的“单独唤醒词”处理器在巡检前直接构造 LLM 请求。真实 @、指令和正常语义关闭路径保持原样。
2. **门禁后的上下文收集**：将独立巡检的真人上下文采集移至后续发送者门禁之后，避免被拦截消息提前进入辅助模型背景。
3. **巡检取消竞态**：窗口已经发放执行资格、等待任务尚未恢复时被取消，也释放组内占用；待处理窗口及执行中巡检合计受上限约束。
4. **判断人格多行**：允许判断人格中的换行，保留长度及非法控制字符校验。
5. **结构化决策解析**：不再把无效外层 JSON 内的嵌套对象当作有效判断；重复字段、错误字段类型及混合无效决策保守拒绝。
6. **保留群专用正则**：关闭再开启专用覆盖时保留已有表达式；只有专用值为空才从通用表达式初始化。

验证：150项离线回归测试；AstrBot 4.29.1真实框架中的32项无网络断言；配置页增删、关联清理、范围扩大二次确认、保存及重载模拟。没有发送真实QQ消息或发起真实模型生成，完整长时间群聊巡检与浏览器视觉验收仍待本人验证。

内部插件ID、配置与SQLite数据目录保持 `astrbot_plugin_peer_context_guard`。旧配置中的语义开关按原值迁移，不自动开启独立语义巡检。删除配置条目不会物理删除现有SQLite历史。
